# Scratch

Scratch is a lightweight CRM for independent golf coaches. Coaches keep a profile for each student, schedule lessons in one calendar, write post-lesson notes and follow-ups, and see which students need attention.

This is a solo final project for CS146S: The Modern Software Developer (Stanford, fall 2026). The project is built with Claude Code across planning, implementation, testing and review.

## Status

Planning. No app code yet. The tech stack is still being decided.

## Repo guide

- `PROJECT_CONTEXT.md` holds the product scope, workflow and current status.
- `CODING_STANDARDS.md` holds the standards that code review checks against.
- `PROMPT_LOG.md` records notable prompts and decisions made with AI tools.

## Workflow

Every change goes through a pull request on its own branch. Each PR gets a CodeRabbit review and a Claude Code review before merging into `main`.
